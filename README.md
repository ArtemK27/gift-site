# 🎄 Симулятор «Чужой смартфон в новогоднюю ночь» (iOS 18 Edition)

Интерактивное новогоднее веб-приложение-подарок для подруги, симулирующее взломанный смартфон на iOS 18 с участием персонажей:
- **Сану** (*Killing Stalking*)
- **Чу Ваньнин и Мо Жань** (*Хаски и его белый кот-Учитель*)
- **Kai Angel & 9mice** (*VIPERR*)

---

## 🚀 Быстрый старт

```powershell
# Установка зависимостей
npm.cmd install

# Запуск локального сервера разработки
npm.cmd run dev

# Продакшн-сборка
npm.cmd run build

# Деплой на GitHub Pages

```

## 📱 Основные возможности
- **Bait-экран**: открытка у камина, взлом системы и переход в локскрин.
- **Экран блокировки iOS 18**: виджеты, уведомления, фонарик/камера, свайп вверх.
- **Свайп вверх (Home Indicator)**: выход из любого приложения по жесту снизу вверх.
- **Живые обои**: многослойный снег, боке, лепестки сливы, реакция на касания пальцем.
- **Мессенджер «ПодвалГрам»**: переписка с персонажами, фото-спойлеры, отправка стикеров (код `20`).
- **Заметки (Apple Notes)**: интерактивные списки ингредиентов и райдера (код `27`).
- **Фото (Apple Photos)**: просмотр артов, EXIF-метаданные и скрытая дверь «КТО ТАМ?».
- **VIP Сейф**: ввод кода `2027`, стирание ледяного покрова на Canvas и выбор новогоднего подарка.
- **Dynamic Island**: музыкальный плеер VIPERR с эквалайзером.
