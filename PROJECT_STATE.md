# 📱 Новогодний Сюрприз 🎄 — Смартфон iOS 18 (Документация и Архитектура)

> **Назначение документа:** Этот документ описывает полную архитектуру, структуру модулей, физику жестов, механику квеста и правила расширения интерактивного веб-приложения «Новогодний Сюрприз 🎄 — Смартфон iOS 18». Документ служит единым источником правды для разработчиков и ИИ-ассистентов в последующих сессиях.

---

## 1. Концепция, фандомы и сеттинг проекта

**Назначение:** Интерактивное веб-приложение — новогодний квест-подарок, оформленный как симулятор смартфона на базе **iOS 18** («Чужой смартфон в новогоднюю ночь»).

### Ключевые персонажи и эстетика:
1. **О Сану (Sangwoo)** — манхва *Killing Stalking* («Убить сталкера»): дерзкий триллер-вайб, бита с гирляндой, новогодний колпак Санты, пентхаус с шампанским, мини-игра «Сапёр» в ПодвалГраме.
2. **Чу Ваньнин и Мо Жань (Тасянь-цзюнь)** — новелла *Erha* («Хаски и его белый кот-Учитель»): темное сянься, белый снег, хунтуни со «стеклом», красные китайские фонарики, божественное оружие Тяньвэнь, заметки с рецептом.
3. **Kai Angel & 9mice** — дуэт *VIPERR*: готика, дарк-гламур, Rick Owens/Opium эстетика, шубы в пол, серебряная мишура, трек «Heavy Metal New Year» в Dynamic Island.
4. **Уютный кот у камина** — праздничный персонаж на стартовом экране-обманке (`BaitScreen`).

### Основной игровой флоу:
- Пользователь начинает на стартовом экране-обманке (`BaitScreen`) или сразу на рабочем столе (`HomeScreen`, также доступен через `?autostart=1`).
- Цель — собрать **4-значный шифр (`2027`)** от приложения **«VIP Сейф»**, исследуя мессенджер «ПодвалГрам», мини-игры, заметки и виджеты.
- Внутри «VIP Сейфа» после ввода пин-кода `2027` открывается **покрытый реалистичной ледяной коркой ваучер**, который нужно стереть пальцем/курсором (`canvas`, порог стирания ≥ 80%), после чего открывается выбор подарка («Золотое Яблоко» или «Сертификат Ozon»).
- Фон телефона (`src/components/LiveWallpaper.tsx`) — глубокий космический черный фон с падающими частицами.

## 2. Архитектурные правила для новых сессий

1. **Модульность приложений (`src/components/apps/`):**
   - Каждое приложение телефона изолировано в отдельном файле `src/components/apps/<AppName>App.tsx`.
   - Порядок добавления нового приложения:
     1. Создайте компонент в `src/components/apps/`.
     2. Добавьте его `id` в тип `AppId` в `src/types/index.ts`.
     3. Добавьте многослойную SVG-иконку в `src/components/home/CustomAppIcons.tsx`.
     4. Зарегистрируйте приложение в `src/components/home/homeAppsData.ts` (Страница 1 или Страница 2).
     5. Подключите рендер окна приложения в `src/components/screens/HomeScreen.tsx`.
2. **Модульность виджетов (`src/components/home/`):**
   - Самостоятельные интерактивные виджеты выносятся в отдельные файлы (например, `src/components/home/FrogClickerWidget.tsx`) и подключаются в `src/components/home/HomeWidgets.tsx`.
3. **Иконки приложений (`CustomAppIcons.tsx` vs `AppIcon.tsx`):**
   - По умолчанию используются детализированные многослойные векторные SVG-иконки из `CustomAppIcons.tsx` (включая аутентичный 8-рогатый значок Сапёра).
   - Для мгновенного отката на классические иконки `lucide-react` достаточно выставить `export const USE_LEGACY_APP_ICONS = true;` в `src/components/home/AppIcon.tsx`.
4. **Стабильность стилей и тем:**
   - Tailwind CSS v3 с кастомными токенами в `tailwind.config.js`: цвета `oled`, `festive-gold`, `cyber-accent`, `festive-emerald`, `alert-crimson`, тени `glass`, `neon-gold`.
   - В `src/index.css` используются стандартные директивы `@tailwind base; @tailwind components; @tailwind utilities;`.

## 3. Адаптивное шасси и физика интерфейса (Chassis & Gestures)

### Адаптивный рендеринг:
- **Mobile Viewport (< 640px):** Полноэкранный режим edge-to-edge на всю высоту экрана (`w-full h-[100dvh] rounded-none border-0`), отсутствие искусственных рамок для полного погружения на смартфонах.
- **Desktop Viewport (≥ 640px):** Центрированный премиальный мокап iPhone 16 Pro (`sm:w-[430px] sm:h-[min(932px,calc(100dvh-48px))] sm:rounded-[56px] sm:border-[10px] sm:border-[#232328] sm:shadow-[0_25px_80px_rgba(0,0,0,0.9)]`) с динамиком сверху и мягким неоновым свечением.

### Изолированный жест выхода (Home Indicator):
- Контейнер `#ios-home-indicator` закреплен в `PhoneShell.tsx` (`h-8 z-50 pointer-events-auto touch-none`).
- Используются Pointer Events (`setPointerCapture`), предотвращая потерю свайпа за пределами экрана.
- Свайп вверх (`deltaY > 25`) или тап по индикатору закрывает активное приложение с естественной spring-физикой iOS:
  - Initial: `{ scale: 0.88, opacity: 0, y: 24, borderRadius: 36 }`
  - Animate: `{ scale: 1, opacity: 1, y: 0, borderRadius: 0 }`
  - Exit: `{ scale: 0.84, opacity: 0, y: -24, borderRadius: 44 }`
- Внутренние списки приложений снабжены классом `touch-pan-y` и `overscroll-contain` для изоляции скролла от жестов выхода.

### Пагинация рабочего стола (SpringBoard):
- Горизонтальный свайп между Страницей 1 и Страницей 2 в `HomeScreen.tsx` управляется единым пиксельным `MotionValue x` с доводкой пружиной и поддержкой `prefers-reduced-motion`.

## 5. Механика квеста и ключи `localStorage`

Все состояния квеста управляются через `SettingsContext.tsx` и сохраняются в `localStorage`:

| Ключ `localStorage` | Тип / Значения | Описание |
|---|---|---|
| `ny2027_cipher_digits_v1` | `Array(4)`: `['2', '0', '2', '7']` | **Шифр от сейфа.** Индексы 0 и 1 (`20`) открываются при чтении чата «Поздравление 🎄» в «ПодвалГраме». Индекс 2 (`2`) открывается в «Заметках». Индекс 3 (`7`) выдаётся при победе в «Сапёре». |
| `ny2027_read_chats_v1` | `string[]` | Список ID прочитанных чатов (по умолчанию пустой; на иконке «ПодвалГрама» горит бейдж `4` → уменьшается до исчезновения). |
| `ny2027_minesweeper_won_v1` | `boolean` | Флаг победы в мини-игре «Сапёр». |
| `ny2027_safe_unlocked_v1` | `boolean` | Флаг успешного ввода ПИН-кода `2027` в Сейфе. |
| `ny2027_selected_gift_v1` | `'goldapple' \| 'ozon' \| null` | Выбранный подарок после стирания льда. |
| `ny2027_frog_clicks_v1` | `number` | Количество кваков в виджете «Жаба удачи 2027 🐸». |
| `ios18_gift_settings` | `object` | Настройки звука, вибрации, частиц и обоев. |

Кнопка **«Сбросить прогресс квеста»** в приложении «Настройки» полностью очищает весь игровой прогресс и возвращает первоначальное состояние.

## 6. Музыкальный плеер Dynamic Island

Плеер работает на базе `AudioContext.tsx`:
- В свёрнутом виде в статус-баре отображается аккуратный чёрный вырез `#000000` с вращающейся пластинкой слева и живым эквалайзером справа.
- По тапу остров плавно раскрывается вниз в интерактивный плеер: обложка, название трека, скраббер с перемоткой, кнопки Next/Prev/Play/Pause.
- **Умная автопауза (`visibilitychange`):** при переключении вкладки браузера воспроизведение автоматически приостанавливается и возобновляется при возвращении, если трек играл.
- **Автопраймирование звука:** первый пользовательский жест автоматически разблокирует аудио-контекст браузера.

### Как заменить музыку своими треками:
1. Поместите MP3 файлы в папку `public/assets/audio/` с именами:
   - `viperr-heavy-metal.mp3`
   - `sangwoo-lullaby.mp3`
   - `erha-snow-melody.mp3`
2. Поместите квадратные JPG обложки (500×500) в `public/assets/`:
   - `cover-viperr.jpg`, `cover-sangwoo.jpg`, `cover-erha.jpg`
3. Либо добавьте новые треки прямо в массив `DEFAULT_TRACKS` в файле `src/context/AudioContext.tsx`.

## 7. Разработка, тестирование и деплой

### Стек:
- React 19, TypeScript, Vite 6, Tailwind CSS 3, Framer Motion 12, Lucide React, Canvas Confetti.

### Команды разработки:
```powershell
# Запуск dev-сервера
npm.cmd run dev

# Проверка типов и сборка бандла
npm.cmd run build

# Предпросмотр собранного приложения
npm.cmd run preview

npm.cmd run test

# Публикация на GitHub Pages
npm.cmd run deploy
```
