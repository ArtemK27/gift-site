## Воспроизведение локальных проверок

Из корня проекта:

```text
npm ci
npx playwright install chromium
npm run build
npx playwright test tests/e2e/home-motion-regressions.spec.ts tests/e2e/milestone3-homescreen-apps.spec.ts tests/e2e/tier4-scenarios.spec.ts
```

`playwright.config.ts` запускает Vite на порту 5173 и разрешает reuseExistingServer. Перед проверкой убедись, что этот порт обслуживает именно текущий проект. Профили:

- `mobile-iphone-16-pro`: 430×932, touch/mobile, iPhone user agent. Движок остаётся Chromium, это не настоящий Safari.
- `desktop-mockup`: 1280×800.

Регрессии `home-motion-regressions.spec.ts` проверяют промежуточные позиции свайпа в обе стороны, возврат короткого жеста, точки/resize, видимость и работу плеера после закрытия приложений. Жесты в этих тестах выполняются через `page.mouse`, а не реальным пальцем.

## Историческая нестабильность

До текущего успешного прогона были падения теста промежуточных кадров свайпа на обоих профилях (2 failed, 18 passed), а также мобильного сценария, не дождавшегося подсказки «20» после стикера. Сегодняшний результат 26/26 не доказывает устранение нестабильности. В сценарии стикера остаются условные `isVisible()` перед кликами; не ослаблять проверки и не считать этот риск закрытым без отдельного разбора.
